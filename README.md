# Hack Pad – Terminal Style Notepad

This is a lightweight, browser-based notepad with a terminal / hacker-style UI.Built for quick notes, drafts, and text files — no backend, no setup. Hope you enjoys this wonderfull Hackpad.


## ✨ Features

- Terminal-inspired UI with Matrix-style background
- Editable text area (like a minimal Notepad)
- Open `.txt`, `.md`, `.js`, `.json` files
- Save notes to a file
- Live character & word counter
- Works fully offline
- No frameworks, no dependencies
- New features are added

## 🚀 How to Use

### Offline use :

1. Clone or download this repository
2. Open `index.html` in your browser
3. Start typing ✍️  
   - Your notes are saved automatically
   - Reloading the page won’t lose your text
     
### Online use :

1. Just open this link and start typting : (https://web-notepad-nine.vercel.app/)
2. That's it you did it , easy as that

## 📂 File Support

With this You can open any kind of file that can be opened with a normal notepad .

Saving works using:
- Native File Picker (supported browsers)
- Automatic fallback download for others

- HTML5
- CSS3

## ⚠️ Notes

- Clearing browser data will remove saved notes
- Matrix animation is visual only (no performance impact on text)

## 📌 Why I Built This

When i was working with a project of mine i used the normal notepad to keep notes and stuff but i felt so much bored with it so i made this Hackpad which look as same as terminal in appearence but works as a notepad. This project can run locally or if you want you can use the link i supplied to use this hackpad. This is a practical way of keeping notes than using a boring notetaker.

This project is mainly for learning, experimenting with UI effects, and keeping notes.
